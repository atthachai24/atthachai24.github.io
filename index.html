📦 Toto Drop

Toto Drop is a personal, single-user tool for passing files and short notes between my own devices and to people I choose. Files are stored in my own Google Drive; the web app hands out a short 6-digit code or link so they can be opened easily.

It is not a public service: only the owner can upload, and it accesses only the files it creates itself in the owner's Google Drive (the drive.file scope).

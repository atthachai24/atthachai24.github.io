Toto Drop – Privacy Policy

Last updated: 10 October 2026

Who uses this app

Toto Drop is a personal tool operated by its owner for their own use. The only Google account connected to it is the owner's.

What Google data it accesses

The app requests only the https://www.googleapis.com/auth/drive.file scope. With it the app can create, read and delete only the files and folders that it created itself in the owner's Google Drive. It cannot see any other file in that Drive.

How the data is used and stored

  • Uploaded files are stored in a "DriveDrop" folder in the owner's Google Drive.
  • The app's server keeps a small database with each item's code, name, size, expiry time and download count. Short text notes are stored in that database.
  • Expired items are moved to the Drive trash and removed from the database automatically.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.

Revoking access

The owner can remove the app's access at any time at myaccount.google.com/permissions.
